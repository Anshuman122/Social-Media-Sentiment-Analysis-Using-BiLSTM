# 🧠 Twitter Sentiment Analysis with LSTM

This project implements a sentiment analysis model on tweets using Natural Language Processing (NLP) and deep learning with a Bidirectional LSTM neural network. It classifies tweets into four categories: Positive, Negative, Neutral, and Irrelevant. The data is preprocessed using standard techniques such as tokenization, lemmatization, stopword removal, and padding. The model is trained on a cleaned and labeled subset of the Twitter training dataset, with labels converted to integers. Tokenized sequences are used as input to a Keras Sequential model featuring an Embedding layer and two stacked Bidirectional LSTM layers followed by a dense softmax output. Model performance is evaluated using a confusion matrix and accuracy metrics. The notebook also includes a full-dataset retraining section for final evaluation and visualization. This project demonstrates end-to-end text classification on social media data using Python, TensorFlow, NLTK, and Scikit-learn.
